## Contributing

When adding a document:

- Use a descriptive filename and a clear title.
- State the intended audience and context near the beginning.
- Distinguish established practices from opinions or exploratory ideas.
- Include sources for claims, recommendations, and external tools.
- Prefer focused documents over one large, hard-to-navigate reference.
- Update links or indexes when adding content to an existing topic area.

## Scope

This is a curated engineering knowledge base, not a framework-specific guide. Recommendations should include enough context to explain when they apply and what trade-offs they involve.
